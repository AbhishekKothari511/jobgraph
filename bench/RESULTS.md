## How to Run

```bash
# 1. Start the stack
docker-compose up -d

# 2. Seed 200 jobs
npm run seed --workspace=scripts

# 3. Baseline (drop indexes first)
psql $DATABASE_URL -c "DROP INDEX IF EXISTS idx_jobs_search_vector, idx_job_embeddings_hnsw, idx_jobs_filters;"
k6 run bench/k6/baseline.js --env BASE_URL=http://localhost:8080

# 4. Recreate indexes
npm run migrate --workspace=supabase

# 5. Indexed
k6 run bench/k6/indexed.js --env BASE_URL=http://localhost:8080

# 6. Cached (run indexed.js once first to warm cache, then cached.js)
k6 run bench/k6/cached.js --env BASE_URL=http://localhost:8080
```
